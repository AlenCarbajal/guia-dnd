# Guía D&D

Guías visuales para personajes de nuestra campaña (D&D 2024 + house rules).

- **Grimorio del Warlock Drow** (`index.html`): cantrips, slot spells, magia drow, rituals e invocations con escenas animadas paso a paso.

Sitio: https://alencarbajal.github.io/guia-dnd/
- **Armador de Personajes** (`armador/`): builder D&D 2024 (SRD 5.2) con reglas de la casa, overrides y homebrew; genera la hoja de personaje de 5 páginas. Guarda en el navegador y exporta/importa JSON.

  https://alencarbajal.github.io/guia-dnd/armador/
